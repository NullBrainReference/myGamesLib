# MyGamesLib

MyGamesLib is an open game pre-production ecosystem designed to transform community discussions and game mechanics proposals into structured development projects. By providing a collaborative design environment alongside a project-first hiring model, it enables gamers and developers to form teams around shared creative visions.

---

## Key Features

### 1. Collaborative Project Creation (Core Team-Building Route)
* **Discussion-to-Project Transition:** Turn forum debates and game design ideas directly into structured project workspaces.
* **Mechanics Proposals:** Co-authors and community members propose, debate, and refine game mechanics prior to full development.
* **Organic Co-Creation:** Teams form naturally around contributed ideas before formal recruitment begins.

### 2. Transparent, Project-First Hiring
* **Project-Centric Applications:** Candidates apply directly to active Game Design Documents (GDD) and live mechanics rather than standard corporate job postings.
* **Two-Way Transparency:** Vacancy statuses, recruitment history, and accepted team rosters are publicly visible to ensure clarity for both applicants and project leads.
* **Structured Recruitment:** Streamlined candidate review workflows with admin capacity management for expanding project position slots.

### 3. Game Catalog & Personal Libraries
* **Catalog & Rating System:** Track games with community metrics, detailed overviews, and score evaluations.
* **User Libraries:** Personal collection management and status tracking for played games.

### 4. Social & Direct Messaging
* **Profiles & Connections:** User profiles showcasing projects, blog posts, and game lists.
* **Direct Messaging:** Real-time 1-on-1 chat integrated with friend lists and profiles.

### 5. Multi-Platform API
* **Sanctum Authentication:** Secure token-based REST API powering both the web client and native mobile applications.

---

## Tech Stack

* **Backend:** PHP / Laravel
* **Database:** MySQL
* **Authentication:** Laravel Sanctum
* **Frontend (Web):** Blade, Tailwind CSS, Alpine.js
* **Mobile Client:** Android (Jetpack Compose via REST API)
